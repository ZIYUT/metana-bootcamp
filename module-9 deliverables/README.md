# Upgradeable Smart Contract Project: NFT Staking System with "God Mode" Upgrade

## Project Overview

This project demonstrates a set of upgradeable smart contracts including an ERC20 token, an NFT, and a staking contract. The NFT contract was upgraded to add a "God Mode" feature that allows the contract owner to forcibly transfer any NFT between addresses.

## Contract Upgrade Details

The contracts being upgraded are originally from module-2 deliverables. The main enhancement in this upgrade is the addition of "God Mode" to the NFT contract, which allows the contract owner to forcibly transfer NFTs between addresses.
